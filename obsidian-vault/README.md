# Bộ não thứ 2 (Obsidian)

Mở Obsidian → **Open folder as vault** → chọn thư mục `obsidian-vault` này.
Claude Code đọc/ghi trực tiếp các file .md ở đây, nên mọi ý tưởng của bạn đều thành "trí nhớ" của AI.

| Thư mục | Ghi gì |
|---|---|
| `00-Inbox` | Ghi nhanh mọi ý tưởng thoáng qua (điện thoại, giọng nói). Cuối tuần Claude phân loại. |
| `10-Y-tuong` | Kho ý tưởng video đã lọc |
| `20-Kich-ban` | Kịch bản sẵn sàng quay |
| `30-Khach-hang` | Chân dung khách, nỗi đau, câu hỏi hay gặp, phản hồi thật |
| `40-Bai-dang` | Caption/bài viết từng video + trạng thái |
| `50-Lich-dang` | Lịch đăng từng tuần |
| `60-Khoa-hoc` | Giáo trình, ghi chú từng bài học đang quay |
| `70-Quang-cao` | Mẫu quảng cáo, số liệu, bài học rút ra |
| `Templates` | Mẫu note (bật plugin Templates, trỏ vào thư mục này) |

Quy tắc vàng: **1 ý = 1 note**, đặt tên rõ, dùng `[[liên kết]]` giữa các note (vd kịch bản → [[Chan-dung-khach-hang]]).
